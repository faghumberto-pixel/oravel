# oravel.org

Site estático de conhecimento para locadoras (HTML + CSS inline, sem build).

Rodar local: `python3 -m http.server 8080` nesta pasta e abrir http://localhost:8080

Páginas feitas: home, reforma-tributaria, la-fora, gestao-e-operacao.
Falta: vendas, tecnologia, comunidade, sobre, privacidade/termos, Gazeta Oravel funcional, sitemap.xml, robots.txt, favicon.
Regras editoriais: toda afirmação com fonte; sem propaganda do sistema; data de revisão; português claro.
Visual: papel #f6f3ec, tinta #1b2230, verde #0b5f57, fundo escuro #12312e, destaque #f59e0b; Newsreader (títulos) + Inter.
