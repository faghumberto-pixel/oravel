Opção A — Plano pra um tipo inteiro de equipamento (recomendado)

  1. Confirme que existe um Grupo de Checklist criado pro tipo de equipamento (ex: "Gerador").
  2. Acesse Manutenção → Planos Preventivos e clique em Criar.
  3. Em vez de escolher um Ativo, selecione o Grupo de Ativo — isso faz o plano valer pra todo equipamento daquele grupo de uma vez.
  4. Defina o Intervalo em horas entre uma preventiva e outra (ex: a cada 250 horas).
  5. Salve. A partir de agora, todo Ativo daquele Grupo passa a mostrar a preventiva sugerida na tela de Ordem de Serviço.

Opção B — Plano pra um equipamento específico

  1. Acesse Manutenção → Planos Preventivos e clique em Criar.
  2. Selecione o Ativo específico em vez de um Grupo.
  3. Defina o intervalo em horas e salve.

Executando a preventiva quando vencer

  1. Abra a Ordem de Serviço do equipamento (ou crie uma nova).
  2. Se o Ativo tiver Grupo de Checklist, use o botão Preventiva (Celular).
  3. Marque os itens do plano conforme forem executados — cada item marcado já avança o horímetro oficial do equipamento.
  4. Use Imprimir Preventiva se precisar de uma via física da execução.
💡 Como saber se algo está vencido

O horímetro de vencimento é sempre "horímetro do último serviço + intervalo do plano". Se o horímetro atual do equipamento já passou disso, a preventiva aparece marcada como vencida na tela da OS e no Dashboard.
