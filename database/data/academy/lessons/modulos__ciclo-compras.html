O Ciclo de Compras é o caminho completo de uma peça: alguém pede, você cota com fornecedores, gera a Ordem de Compra e, quando a peça chega, o Recebimento atualiza o estoque sozinho.

📦 Entrega parcial é normal

Se o fornecedor entregar em várias remessas, registre um recebimento para cada uma. A ordem vira Parcialmente recebida e passa a Recebida quando tudo chegar. Ao confirmar, a quantidade recebida é somada automaticamente ao estoque. Para peças que exigem nº de série, o sistema não deixa receber sem informar.

Detalhes do módulo

👤 Quem usa

Técnico ou supervisor abre a Requisição; Compras cota e gera a Ordem; almoxarifado confirma o Recebimento.

As 4 etapas

  1. Requisição de Peças — alguém pede uma peça, geralmente a partir de uma Ordem de Serviço em andamento, mas também pode ser aberta manualmente. Tem prioridade (ex: Normal, Urgente).
  2. Cotação — o setor de Compras registra os preços obtidos com um ou mais Fornecedores, a partir da Requisição.
  3. Ordem de Compra — gerada a partir da Cotação escolhida (ou direto, sem Requisição prévia, pra compra avulsa). É o documento formal de compra com o fornecedor.
  4. Recebimento — quando a peça chega, você confirma o recebimento contra a Ordem de Compra. Pode ser parcial (recebimentos em várias entregas pra uma mesma Ordem).

Compra sem Requisição prévia

Nem toda compra precisa começar de uma Requisição — dá pra criar uma Ordem de Compra direto, pra reposição de estoque geral ou compras avulsas que não vêm de uma OS específica.
