Toda vez que uma Ordem de Serviço é criada, o sistema monta sozinho o checklist de vistoria dela, copiando os itens do Grupo de Checklist do ativo mais os itens extras cadastrados no próprio ativo.

📍 Modelo: Ativos → Gestão de Ativos → Grupos de Ativos · Preenchimento: Manutenção → Operação → Ordens de Serviço (aba Vistoria / Checklist)

O modelo e a cópia

1Modelo (template)Itens básicos do Grupo + itens extras do ativo.
2OS é criadaO sistema gera o checklist sozinho.
3Cópia na OSO técnico preenche o checklist real.

Os três status de cada item

StatusSignificado
ConformePonto de inspeção OK.
Não ConformePonto com problema — o item não conta como concluído.
Não AplicávelO item não se aplica a este atendimento.
📋 Sempre uma cópia

Editar o modelo do Grupo ou do ativo depois não muda checklists de OS que já existem — só vale para as novas.

📱 Pelo celular

A tela mobile mostra os itens com uma barra de progresso; o botão Finalizar só libera quando o checklist chega a 100%.

🗂️ Não confunda

No menu de Manutenção há também um cadastro genérico chamado Checklists, sem ligação com ativo, grupo ou OS. O fluxo real de vistoria é o descrito aqui.

👤 Quem usa

Supervisor de manutenção cadastra os itens padrão do Grupo/Ativo; o técnico preenche o checklist real dentro da OS, normalmente pelo celular.

Quando usar

  • Ao configurar quais pontos de inspeção todo equipamento de um Grupo deve ter (cadastro, na tela do Grupo de Checklist).
  • Ao adicionar um ponto de inspeção específico de um Ativo só (na tela do próprio Ativo).
  • Ao preencher a vistoria de uma OS em andamento.

Template x Checklist real da OS

Existem dois níveis: o template (itens básicos do Grupo de Checklist, mais itens extras específicos de um Ativo) e o checklist real, que é uma cópia desses itens gerada automaticamente na hora em que uma OS nasce.

💡 É sempre uma cópia, nunca uma referência ao vivo

Editar o template do Grupo ou do Ativo depois não muda nada em checklists de OSs que já existem — só afeta OSs novas, criadas depois da edição.

Preenchendo o checklist na OS

Cada item recebe um dos três status abaixo, além de observação e foto opcionais:

Pelo celular

A tela mobile mostra os itens já gerados na OS com uma barra de progresso; o botão "Finalizar" só libera quando o checklist chega a 100%.

⚠️ Existe um cadastro "Checklists" solto, sem relação com este fluxo

Há também um cadastro genérico de nome/descrição chamado Checklists no menu de Manutenção que não tem nenhuma ligação com Ativo, Grupo de Checklist ou Ordem de Serviço — não confunda com o fluxo real de vistoria descrito acima.
