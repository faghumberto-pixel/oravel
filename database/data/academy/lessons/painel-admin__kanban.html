O Kanban do Pátio é um quadro de arrastar-e-soltar para acompanhar todo o pátio de manutenção de relance: cada coluna é uma etapa e cada cartão é uma Ordem de Serviço.

📍 Manutenção → Operação → Kanban do Pátio

O quadro no modo Fluxo de Oficina

1Aguardando DiagnósticoA OS chegou e ninguém avaliou ainda.
2Em ManutençãoO técnico está trabalhando.
3Aguardando PeçaMarcada como Gargalo: parada esperando material.
4Teste de QualidadeServiço feito, em teste.
5PendênciaFalta algo para fechar.
6ConcluídoTudo certo.

O quadro no modo Painel Comercial

🖱️ Arrastar muda o status

Arrastar um cartão para outra coluna atualiza o status da OS na hora e fica registrado no histórico (quanto tempo ficou em cada etapa).

🚨 Borda vermelha = locação urgente

Se o equipamento do cartão está reservado numa Solicitação de Locação marcada como Reservar para Manutenção (Urgente), o cartão ganha borda vermelha e o aviso “Locação Urgente Aguardando Este Ativo”.

👤 Quem usa

Equipe de Manutenção/Oficina — técnicos e supervisores acompanhando o fluxo do pátio no dia a dia.

Quando usar

  • Pra ver rapidamente quantas OS estão em cada etapa do atendimento.
  • Pra mover uma OS de estágio arrastando o cartão.
  • Pra saber quais equipamentos precisam ser priorizados por causa de uma locação urgente.

Dois modos de visão

ModoColunas
OficinaAguardando Diagnóstico → Em Manutenção → Aguardando Peça (marcado como "Gargalo") → Teste de Qualidade → Pendência → Concluído
ComercialDisponível no Pátio → Em Obra → Retido/Oficina

Arrastar um cartão pra outra coluna atualiza o status da OS na hora, e fica registrado no histórico de mudanças de status daquela OS (quanto tempo ficou em cada etapa aparece no próprio cartão).

Destaque de urgência comercial

Se o equipamento de um cartão está reservado numa Solicitação de Locação marcada como "Reservar para Manutenção (Urgente)", o cartão ganha uma borda vermelha e um aviso "⚠ Locação Urgente Aguardando Este Ativo" — um jeito de a oficina saber, sem precisar perguntar ao comercial, que aquele equipamento específico está sendo esperado por um contrato prestes a fechar.
