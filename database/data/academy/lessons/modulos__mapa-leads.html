Menu: Comercial → Mapa Comercial
👤 Quem usa

Vendedores (só os próprios leads/clientes no mapa) e admin da empresa (carteira completa).

Como funciona

Só aparecem no mapa os registros com endereço já geolocalizado — o que acontece sozinho ao preencher o CEP no cadastro de Cliente ou Lead. Cada marcador mostra nome, empresa e (no caso do Lead) estágio no funil ao clicar, com um link direto pro cadastro completo. Clientes e Leads aparecem juntos no mesmo mapa, com cores diferentes.

💡 Sem custo de API

O mapa usa OpenStreetMap — não depende de uma chave de API do Google Maps nem tem custo por uso.
