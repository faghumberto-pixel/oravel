Acessado pelo QR Code impresso no Ativo, ou pela busca no painel
👤 Quem usa

Técnico ou comercial em campo/pátio, escaneando o QR Code com o celular. Também existe uma versão desktop no painel, pra quem tem acesso a Ativos.

Quando usar

  • Ao chegar perto de um equipamento no pátio e querer saber o histórico dele na hora.
  • Antes de negociar uma locação, pra confirmar disponibilidade e horas trabalhadas.

O que aparece na tela

  • Dados gerais: categoria, status, especificação, criticidade (Matriz ABC)
  • Cliente atual e Contrato vigente (nº, início, valor mensal)
  • Horas trabalhadas (horímetro, e odômetro se for veículo)
  • Avarias recentes (últimas 5)
  • Ordens de Serviço abertas (nº, técnico, problema)

A etiqueta física

Na tela de edição do Ativo existe o botão Imprimir Etiqueta, que gera um QR Code apontando direto pra esta tela mobile — é essa etiqueta que deve ficar colada no equipamento.

Buscando pelo computador

Pelo painel (versão desktop), a busca aceita termos parciais — nome, tag, patrimônio ou número de série — não precisa digitar o valor exato.
