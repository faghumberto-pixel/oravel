A Oravel Academy é o seu guia completo do sistema: o que cada área faz, como cada módulo funciona, para quem é e quando usar.

Como estudar aqui

1Escolha um móduloTodos estão no menu lateral. Não existe ordem obrigatória: faça só os que você precisa, quando quiser.
2Leia e veja as telasCada aula mostra a tela real do sistema, com números explicando cada parte.
3Faça a provaResponda e entregue. O gabarito aparece na hora, e cada acerto vale pontos.
4Receba o certificadoConclua o curso e atinja a nota mínima para baixar o seu certificado.
